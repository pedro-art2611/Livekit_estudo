# livekit_estudos

Projeto de estudos e análise técnica sobre LiveKit aplicado ao contexto da MB Finance.

## Objetivo

Avaliar se uma migração ou complementação da ElevenLabs com LiveKit faz sentido para a operação da empresa.

## Contexto

A MB Finance utiliza ElevenLabs para agentes de voz, mas existe preocupação com:

- custo elevado;
- subutilização de recursos contratados;
- limitações de funcionalidades;
- necessidade de maior controle;
- desejo de criar front-end próprio;
- integração com API interna, n8n, webhooks e sistemas internos.
