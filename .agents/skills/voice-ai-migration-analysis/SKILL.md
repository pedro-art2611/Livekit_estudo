# Voice AI Migration Analysis Skill

## Objetivo
Avaliar se faz sentido migrar uma operação de agentes de voz de uma plataforma pronta, como ElevenLabs, para uma arquitetura própria ou híbrida usando LiveKit e componentes externos.

## Use para
- Comparar ElevenLabs com LiveKit.
- Avaliar custo e benefício.
- Identificar gaps de features.
- Avaliar viabilidade técnica.
- Avaliar esforço de desenvolvimento.
- Avaliar riscos de manutenção.
- Planejar MVP de migração.
- Preparar perguntas para reunião.
- Criar documento de decisão técnica.
- Avaliar abordagem híbrida.

## Perguntas principais
Sempre responder ou levantar:

1. Qual problema real queremos resolver?
2. O problema é custo, feature, controle ou tudo junto?
3. O que a ElevenLabs entrega pronto hoje?
4. O que estamos usando pouco ou pagando sem usar?
5. O que a ElevenLabs não permite fazer?
6. O que o LiveKit entrega nativamente?
7. O que precisaríamos construir?
8. Quais serviços externos ainda seriam necessários?
9. Quanto esforço técnico isso adiciona?
10. Quem vai manter?
11. Como testaríamos um MVP?
12. Qual critério indicaria que a migração vale a pena?
13. Existe caminho híbrido melhor que migração total?

## Dimensões de análise
Avalie sempre:

- custo atual;
- custo estimado futuro;
- tempo de desenvolvimento;
- complexidade técnica;
- manutenção;
- latência;
- qualidade de voz;
- qualidade de STT;
- qualidade de TTS;
- integração com sistemas internos;
- integração com n8n;
- observabilidade;
- logs;
- segurança;
- controle do fluxo;
- facilidade para operadores;
- dependência de fornecedores;
- escalabilidade;
- risco operacional.

## Formato de resposta
1. Diagnóstico
2. Dores atuais
3. O que ElevenLabs entrega
4. O que LiveKit entrega
5. O que precisaria ser construído
6. Comparação crítica
7. Riscos
8. MVP sugerido
9. Critérios de sucesso
10. Perguntas para reunião
11. Recomendação inicial
