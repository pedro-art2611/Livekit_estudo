# Internal Voice AI Frontend Skill

## Objetivo
Planejar front-end próprio para operar, configurar, testar e monitorar agentes de Voice AI.

## Use para
- Desenhar dashboard interno.
- Planejar tela de configuração de agentes.
- Planejar histórico de chamadas.
- Planejar visualização de logs.
- Planejar testes de agentes.
- Definir integração com API própria.
- Definir permissões e usuários internos.

## Possíveis módulos
- Agentes.
- Prompts.
- Configurações.
- Testes.
- Chamadas.
- Logs.
- Métricas.
- Webhooks.
- Integrações.
- Erros.

## Formato de resposta
1. Usuários internos
2. Objetivo do painel
3. Telas necessárias
4. Fluxos principais
5. Dados necessários
6. Integrações
7. MVP
8. Riscos
