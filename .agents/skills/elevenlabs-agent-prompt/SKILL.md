# ElevenLabs Agent Prompt Skill

## Objetivo
Criar prompts profissionais para agentes de voz na ElevenLabs com boa naturalidade, regras claras, fluxo consultivo e restrições seguras.

## Use para
- Criar agente de vendas.
- Criar agente de atendimento.
- Criar agente de qualificação.
- Melhorar primeira mensagem.
- Tratar objeções.
- Reduzir respostas longas.
- Corrigir comportamento estranho.
- Criar testes de agente.
- Migrar lógica conversacional da ElevenLabs para arquitetura própria.

## Estrutura recomendada
1. Identidade do agente
2. Objetivo da ligação
3. Fluxo sugerido
4. Diagnóstico
5. Apresentação da solução
6. Tratamento de objeções
7. Tom e personalidade
8. Restrições absolutas
9. Encerramento
10. Casos de teste

## Formato de resposta
1. Diagnóstico do prompt
2. Melhorias necessárias
3. Prompt revisado
4. Primeira mensagem
5. Objeções
6. Restrições
7. Testes
