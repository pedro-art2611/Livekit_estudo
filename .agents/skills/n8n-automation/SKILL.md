# n8n Automation Skill

## Objetivo
Planejar, implementar e revisar workflows n8n úteis, seguros e fáceis de manter.

## Use para
- Criar webhook.
- Chamar API via HTTP Request.
- Manipular JSON.
- Integrar sistemas.
- Salvar dados em PostgreSQL/Neon.
- Acionar IA.
- Criar automações de atendimento.
- Tratar erros e retries.

## Formato de resposta
1. Objetivo do workflow
2. Gatilho
3. Nodes
4. Payloads
5. Tratamento de erro
6. Logs
7. Teste
8. Melhorias futuras
