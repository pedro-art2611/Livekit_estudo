# Prompt Engineering Skill

## Objetivo
Criar prompts claros, seguros, testáveis e adequados ao canal.

## Use para
- Criar system prompt.
- Melhorar agente.
- Corrigir comportamento.
- Reduzir alucinação.
- Criar regras.
- Criar exemplos.
- Criar testes.
- Definir tool calling.

## Formato de resposta
1. Diagnóstico
2. Problemas
3. Prompt revisado
4. Regras
5. Testes
6. Riscos
